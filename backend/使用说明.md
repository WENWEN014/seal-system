# 证照印章管理系统（CSV 长表版）- 使用说明

## 一、核心变化：数据模型重构

不再用 Excel 宽表（一行一家公司、章压成 0/1 列），改成 **CSV 长表**：

> **最小数据单元 = 每一枚章 / 每一份执照，各自一行，独立记录位置与流转。**

原《刻章情况.xlsx》的 378 行宽表，反透视后变成 **1542 行**长表（1164 枚章 + 378 份执照）。

---

## 二、三个 CSV 文件

数据目录：**`E:\证照印章数据`**（当前为本机使用；可用环境变量 `SEAL_DATA_DIR` 改，后续换共享盘时改一行即可）。

数据源头仍是 `Z:\ceshi\刻章情况.xlsx`（只读，用于生成 CSV）。

### 1. `items.csv` — 资料明细（1542 行，核心）

一行 = 一枚章或一份执照，记录它**当前在哪、什么状态**。

| 列名 | 说明 |
|---|---|
| item_id | 唯一编号，如 IT00001 |
| 公司名称 / 家族 / 法人 | 归属信息 |
| 资料类型 | 公章 / 法人章 / 财务章 / 合同章 / 发票章 / 营业执照 |
| 资料类别 | 章 / 执照 |
| 当前位置ID / 当前位置 | 在哪个筐，或在谁手上 |
| 当前位置类型 | 位置 / 人员 |
| 状态 | 在库 / 在外部 / 已缴销 |
| 持有人 | 在外部时是谁拿着 |
| 出库时间 / 更新时间 / 备注 | 时间与备注 |

### 2. `locations.csv` — 位置与人员统一节点（31 行）

**位置（筐 / 柜）和人员放在同一张表里**，都作为流转的节点，这样"位置 ⇄ 人员 ⇄ 位置"才成立。

| 列名 | 说明 |
|---|---|
| id | L001…（位置） / P001…（人员） |
| 名称 | 如 Veimia01、向向 |
| 类型 | 位置 / 人员 |
| 柜子 | 所属柜（位置才有） |
| 关联家族 | 位置归属哪个家族 |
| 负责人 | 这个位置/人员归谁管 ← **人员与位置的归属关系** |
| 备注 | 说明 |

### 3. `movements.csv` — 流转轨迹（核心）

**每一次移动都留痕**，这是"章的位置变更轨迹"的完整记录。

| 列名 | 说明 |
|---|---|
| 事件ID / 时间 | 唯一编号与时间 |
| item_id / 公司名称 / 资料类型 | 哪一枚章 |
| 动作 | 出库 / 归还 / 调拨 / 缴销 / 入库 / 新增 / 删除 / 编辑 |
| 起点ID / 起点名称 / 起点类型 | 从哪来（位置还是人员） |
| 终点ID / 终点名称 / 终点类型 | 到哪去（位置还是人员） |
| 操作人 | 谁操作的 |
| 事由 | 为什么 |

## 三、流转链路示例

一枚章的完整生命周期，在 `movements.csv` 里是这样一串：

```
2026-09-30 出库  Veimia01(位置) → 向向(人员)    李四  变更（法人）
2026-10-08 归还  向向(人员)     → 神龙01(位置)  李四  法人变更完成
2026-10-09 调拨  神龙01(位置)   → 金狮01(位置)  李四  家族调整
```

**三种链路全覆盖**：
- 位置 → 人员（出库 / 拿去办事）
- 人员 → 位置（归还 / 办完放回）
- 位置 → 位置（调拨 / 换家族换筐）

查任何一枚章，都能看到它从哪来、到哪去、经过谁的手。

## 五、使用步骤（后台静默模式）

已完成配置：**开机登录后服务自动在后台静默运行（无任何窗口），你只需双击桌面图标打开看板。**

### 日常使用
双击桌面 **「证照印章管理系统」** → 浏览器直接打开看板。

- 服务正常情况下 1 秒内打开
- 万一服务没在跑（比如被安全软件拦了），双击时会自动在后台拉起服务，等就绪后打开浏览器
- 启动失败才会弹提示框

### 桌面两个图标

| 图标 | 作用 |
|---|---|
| **证照印章管理系统** | 打开看板（服务未运行时自动后台拉起） |
| **停止证照印章服务** | 停掉后台服务（用完想释放资源时点，会弹提示确认） |

### 开机自启
登录 Windows 后，`SealService-AutoStart.vbs` 会自动在后台启动服务，**不弹任何窗口、不自动打开浏览器**。需要看板时双击桌面图标即可。

> 自启脚本位置：`C:\Users\Administrator\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\`
> 若火绒拦截，选择"允许"即可（该脚本仅启动本机 Python 服务）。

### 手动维护（需要看服务日志时）
- 双击 `server\start_service.bat` → 带窗口启动，能看到实时日志
- 双击 `server\stop_service.bat` → 停止服务

> 后续要给同事看时，把 `http://192.168.x.x:8000` 发给他们即可——他们不用装任何东西，前提是你的电脑开着。

## 五之二、前台 / 后台（权限）

同一个网址，两种视角：

| | 前台（同事，打开即是） | 后台（管理员，需登录） |
|---|---|---|
| 可见页面 | 看板、查询定位、柜子图、出入库 | 上述 4 个 + 流转轨迹、盘点导出、数据管理 |
| 柜子图 | 只读，不可拖动 | 可拖动调整筐位置 |
| 出入库 | 只看记录台账 | 可执行出库 / 入库 / 调拨 |
| 数据管理 | 无 | 新增公司、批量导入、下载 CSV、设置操作人 |

- 登录：右上角「管理员登录」→ 账号 **二维** → 登录状态**保留 7 天**
- 操作人姓名可在「数据管理 → 操作人」里修改，会记入所有留痕
- 权限为**界面级**（内网信任环境）：前台无任何操作入口，写接口需登录令牌

> 同事访问：把 `http://你的内网IP:8000` 发给他们，无需安装、无需登录。

## 六、页面说明

| 页面 | 前台 | 后台额外能力 |
|---|---|---|
| **看板** | 总览：公司数、章证总数、在库、在外部、待定位、已缴销；在外部按人汇总；各家族统计 | — |
| **查询定位** | 输公司名/法人/家族/章类型/位置 → 看到这枚章在哪、什么状态 | — |
| **柜子图** | 柜子 × 4 排 × 3 位网格，点筐看清单 | **新增 / 改名 / 删除柜子**、拖动筐调整位置（跨柜、插入挤开）、新增筐/人员、**改名 / 删除筐** |
| **出入库** | 只看出入库记录台账 | **出库 / 入库 / 调拨** 三个功能 |
| **流转轨迹** | — | 查任意章完整链路；按人员/位置看流向汇总 |
| **盘点导出** | — | 勾选柜子/筐（多选）→ 按公司矩阵式盘点表，导出 Excel / 明细 CSV / 打印 |
| **数据管理** | — | 下载 CSV、新增公司、批量导入、设置操作人 |

### 柜子布局规则
- 每个柜 **4 排 × 每排 3 个筐位**（共 12 位）
- 当前：柜一 / 柜三 / 柜六 各 9 个筐（占满 3 排，第 4 排空）；柜二 / 柜四 / 柜五 全空（留给国外执照）
- 不需要每排放满，空着即可；拖动时后面的筐自动挤开，放不下时会提示

### 新增柜子（后台）
1. 管理员登录 →「柜子图」→ 左上角 **＋ 新增柜子**
2. 弹窗里默认给下一个柜名（如 柜七），可改 → 点「新增」
3. 新柜子为空柜（12 个空位），之后在柜内用「＋ 新增筐」放筐，或直接把别的柜的筐拖进来
4. 名称不能与已有的柜子 / 筐 / 人员重复；新建记录会写入 `locations.csv`（类型=柜子）并在流转轨迹留痕

### 盘点导出（后台，一行一家公司）
1. 「盘点导出」→ 在**勾选面板**里勾选要盘点的范围 + 选类别（全部 / 章 / 执照）→ 页面直接出表
2. **勾选规则**（多选，不再只能选一个筐）：
   - 位置按「柜子 → 筐」分组显示，筐名一律带柜子前缀，如 `柜一-吉喵云01`
   - 勾柜子 = 整柜全选；展开后**可单独取消某个筐**（柜子框变半选状态）
   - 顶部「全部」= 所有柜所有筐；「清空」= 一个都不选（此时需先勾选才能导出）
   - 从筐详情点「生成盘点清单」跳过来时，会自动勾中该筐
3. 表头：`序号 | 柜子 | 筐 | 公司 | 公章 | 法人章 | 财务章 | 合同章 | 发票章 | 营业执照 | 实际核对`（柜子/筐/公司列纵向合并）
4. 排序：按 **柜子 → 筐 → 公司名**（顺着柜子走，方便实际核对）；「柜子」「筐」两列标明每家公司资料的所在位置
5. 单元格含义：

| 写法 | 含义 |
|---|---|
| `✓` / `✓×2` | 该章就在这个筐里（×2 = 2 枚） |
| `无` | 这个筐里没有（公司没办过，或不在此筐） |
| `向向处` | 该章被外带，在**持有人**那里（自动写人名 + "处"） |
| `吉喵云02` | 该章在**没勾选的别的筐**里（写筐名） |
| `已缴销` | 办过但已缴销 |

6. 一家公司最多两行：**第一行**是该筐里的情况，**第二行**（有才显示）写不在盘点范围的章的实际位置；未上架的执照（待分配）不列出，免得每家都多一行
7. 按钮：**导出 Excel**（.xlsx，合并单元格 + 边框，打印可直接用）、**导出明细 CSV**（一行一枚章，同样带柜子/筐列）、**打印**
8. 文件名自动生成：整柜 → `柜一-盘点表-日期.xlsx`、多柜 → `柜一+柜三-盘点表-日期.xlsx`、少量筐 → `柜一-精灵02-盘点表-日期.xlsx`、全部 → `全部位置-盘点表-日期.xlsx`
9. 导出 Excel 依赖服务器上的 openpyxl，缺了会提示；已装在 `E:\Python313`

### 柜子 / 筐 的改名与删除（后台）
| 操作 | 入口 | 规则 |
|---|---|---|
| **柜子改名** | 柜子图 → 柜子标题栏「改名」 | 柜内所有筐的所属柜子、流转轨迹里的旧名字会同步更新 |
| **删除柜子** | 柜子图 → 柜子标题栏「删除柜」 | 柜里只要还有**装了资料的筐**就不允许删（会提示是哪几个筐）；空筐会随柜子一起删除 |
| **筐改名** | 柜子图 → 点某个筐 → 弹窗里「改名」 | 筐内资料的所在位置、流转轨迹里的旧名字会同步更新 |
| **删除筐** | 柜子图 → 点某个筐 → 弹窗里「删除筐」 | 筐里还有资料（未缴销）就不允许删，提示先调拨或缴销 |

- 改名时新名称不能和已有的柜子 / 筐 / 人员重名；改名会在流转轨迹里留一条「改名」记录（旧名 → 新名）
- 删除不可恢复，删除前弹窗会列出将一起删除的内容，确认后才执行
- 筐里资料太多不想一个个调拨时：先在「出入库 → 调拨」把整筐资料调到别的筐，再来删除

### 出库 / 入库 / 调拨（后台）
| 功能 | 能勾选的章 | 目标 | 场景 |
|---|---|---|---|
| **出库** | 在库的章 | 人员 | 拿去办事（如给向向办理变更） |
| **入库** | 在外部（在某人处）的章 | 筐 | 办完拿回来放回柜子 |
| **调拨** | 在库的章 | 筐 | 换筐 / 换家族，可填事由与新法人 |

操作方式：三个功能都可**一次勾选多家公司**，每家公司展开后逐枚勾选章，填一次目标和事由，一次执行全部。

## 七、⚠️ 注意事项

**1. CSV 被 Excel/WPS 打开时无法写入**
看板改数据时要能写文件。如果 CSV 正开着，会提示失败。关掉再试即可。

**2. 同一时刻只让一台电脑跑服务**
CSV 不支持多人同时写。谁要录入，谁启动服务；录入完关掉。这符合"一人负责录入"的流程。

**3. 当前数据目录是 `E:\证照印章数据`**

`Z:\ceshi` 目前不可写（报 `Permission denied`，共享盘权限问题），所以先放 E 盘本机使用。

后续要换成共享盘时，两种方式任选：
- 改 `② 启动看板.bat` 第 12 行的 `SEAL_DATA_DIR`
- 或在命令行里指定：
  ```bat
  set SEAL_DATA_DIR=Z:\ceshi
  python server.py
  ```
  然后把三个 CSV 拷到目标目录即可。
